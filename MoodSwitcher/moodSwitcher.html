Project 7--DOM and JS

JavaScript Questions

1. Why is textContent safer than innerHTML?

Answer: textContent treats content as plain text instead of HTML, so unwanted HTML cannot be added to the page.

2. How are HTML elements connected to JavaScript variables using DOM selection?

Answer: We use document.querySelector() to select an HTML element and store it in a JavaScript variable.

3. What would happen to the text box with id="text" if I added this line to the code above it:

text.textContent = "Hello!"

Answer: If text refers to the selected element, its text would be replaced with Hello!
